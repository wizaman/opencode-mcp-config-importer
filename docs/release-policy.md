## 現在決まっていること

- OpenCode V2 プラグインとして npm に公開し、JSR へは公開しない。開発に Deno を使うことと、JSR で配布することは別である。二重公開による運用の複雑さも避ける。
- パッケージのメタデータとバージョンは `package.json` を正本とする。
- OpenCode が TypeScript ソースを直接読み込める範囲ではビルド工程を設けず、必要になった場合も生成物を最小限にする。
- 公開前にテスト・lint・型チェック、バージョンの整合、npm に含まれるファイルを確認する。ローカルのソースだけでなく、配布物としての動作も確認する。

## 手順を確定する前に検討すること

初回公開の手順は未確定である。バージョンの更新方法、配布物の検証方法、CI と公開権限の連携、npm の認証・provenance、Git タグと GitHub Releases の扱い、試験公開の要否を精査してから、この文書に手順を追加する。現時点で自動公開や Release の不使用を決定したわけではない。
